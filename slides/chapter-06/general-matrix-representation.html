Matrix representation
General matrix elements and the l = 1 example
10 / 15
Guided reading

The matrix representation uses the (|l,m angle) basis. For a fixed \(l\), the Hilbert subspace has dimension (2l+1).

Operator expansion
\[\hat L_z=\sum_{m',m}\langle l,m'|\hat L_z|l,m\rangle |l,m'\rangle\langle l,m|\]
\[\hat L_\pm=\sum_{m',m}\langle l,m'|\hat L_\pm|l,m\rangle |l,m'\rangle\langle l,m|\]

The same construction is written for \(\hat L^2\).

Matrix elements
\[\langle l,m'|\hat L_z|l,m\rangle=m\hbar\delta_{m',m}\]
\[\langle l,m'|\hat L^2|l,m\rangle=l(l+1)\hbar^2\delta_{m',m}\]
\[\langle l,m'|\hat L_\pm|l,m\rangle=\sqrt{l(l+1)-m(m\pm1)}\,\hbar\,\delta_{m',m\pm1}\]
Basis for l = 1
\[|1,+1\rangle=\begin{pmatrix}1\\0\\0\end{pmatrix},\qquad |1,0\rangle=\begin{pmatrix}0\\1\\0\end{pmatrix},\qquad |1,-1\rangle=\begin{pmatrix}0\\0\\1\end{pmatrix}\]

The ordered basis is \(|1,+1\rangle, |1,0\rangle, |1,-1\rangle\).

l = 1 component matrices
\[\hat L_z=\hbar\begin{pmatrix}1&0&0\\0&0&0\\0&0&-1\end{pmatrix}\]
\[\hat L_x=\frac{\hbar}{\sqrt2}\begin{pmatrix}0&1&0\\1&0&1\\0&1&0\end{pmatrix},\qquad \hat L_y=\frac{\hbar}{\sqrt2}\begin{pmatrix}0&-i&0\\i&0&-i\\0&i&0\end{pmatrix}\]
