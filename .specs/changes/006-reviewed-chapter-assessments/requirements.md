# Requirements

1. Every delivered item must identify its chapter and reviewed-page reference.
2. The delivery API must send no answer key before submission.
3. The server must grade submitted attempts and record a private result.
4. Only Chapters 1–7 are eligible.
5. Generated questions must use only the reviewed page context; they must not copy a textbook exercise or solution.
6. Each delivered assessment must visibly offer a learner error-report flow for the statement/options and the answer key/explanation.
7. Reports must enter the existing private administrator validation queue; only marioreis@id.uff.br can review them.
8. Confirmed reports must identify the exact generated item and its reviewed-page reference so that future generation can be corrected.
