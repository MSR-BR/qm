# Acceptance criteria

- An unauthenticated visitor sees an English sign-in explanation and no official totals.
- Completing a published section creates one authoritative event and awards its configured points only once.
- Repeating the same action is deduplicated.
- A learner can read only their own profile and events.
- Chapters 8–13 cannot create or receive rewards.
- The assessment area contains only a truthful availability message until reviewed item banks are approved.
