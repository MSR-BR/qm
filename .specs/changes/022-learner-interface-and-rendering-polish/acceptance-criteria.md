# Acceptance criteria

- [x] Header actions look and behave as buttons at desktop and mobile widths.
- [x] No share surface emits Portuguese or mixed-language copy.
- [x] Assessment controls do not overflow at 320 px and a repeated tap cannot create duplicate requests or duplicate errors.
- [x] Every favorite exercise resolves through the saved/favorite union and opens its complete statement and solution.
- [x] Exercise-list previews contain no raw MathJax delimiters and full details render mathematics through the existing formatter and MathJax pipeline.
- [x] First authenticated use presents the current privacy acknowledgement and a separate, unchecked optional-update choice.
- [x] Consent can be changed later in Personal Area.
- [x] Keyboard, focus, screen-reader, reduced-motion, and 200% text-zoom checks pass locally.

Authenticated production confirmation remains a release-evidence gate; it is not an unresolved local implementation item.
