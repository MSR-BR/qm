# Acceptance criteria

- [ ] Optional communication is off until affirmative opt-in.
- [ ] Caps, quiet hours, pause, and one-click unsubscribe are server-enforced.
- [ ] Messages use only reviewed eligible activities, explain why, and contain no coercive loss/urgency.
- [ ] Delivery failure cannot block the learning app.
- [ ] GA4/product analytics cannot award points, mastery, or message eligibility.
- [ ] Reports name the exact outcome, population, denominator, exposure, uncertainty, and limitations.
- [ ] Engagement or satisfaction is never reported as learning gain.
- [ ] Production sending remains disabled until sender verification and explicit release authorization.
