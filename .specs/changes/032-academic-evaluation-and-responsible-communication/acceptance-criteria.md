# Acceptance criteria

- [x] Optional communication is off until affirmative opt-in.
- [x] Caps, quiet hours, pause, and one-click unsubscribe are server-enforced.
- [x] Messages use only reviewed eligible activities, explain why, and contain no coercive loss/urgency.
- [x] Delivery failure cannot block the learning app.
- [x] GA4/product analytics cannot award points, mastery, or message eligibility.
- [x] Reports name the exact outcome, population, denominator, exposure, uncertainty, and limitations.
- [x] Engagement or satisfaction is never reported as learning gain.
- [x] Production sending remains disabled until sender verification and explicit release authorization.
