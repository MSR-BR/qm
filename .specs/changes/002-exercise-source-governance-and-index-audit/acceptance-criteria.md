# Acceptance criteria

- Generated exercise manifests and public topic-index documentation contain only Chapters 1–7.
- Every manifest entry identifies an existing app page, a book reference, and at least one source PDF filename.
- Validators fail if a non-eligible chapter appears in an exercise-facing index.
- The local audit produces a coverage summary without printing credentials or book contents.
- The remote Supabase project reference is recorded as either verified or explicitly pending; no remote mutation is made.
