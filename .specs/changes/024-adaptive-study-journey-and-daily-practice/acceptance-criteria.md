# Acceptance criteria

- [ ] Study Journey values come from one consistent learner profile.
- [ ] A Daily Challenge is available for signed-in learners with eligible reviewed content.
- [ ] Chapter assessment is offered near chapter completion and remains distinct from Daily Challenge.
- [ ] Wrong and low-confidence answers produce feedback and a focused retry; successful retrieval changes the future interval.
- [ ] Recommendations disclose why they were selected and link to reviewed material.
- [ ] The system has a deterministic fallback and never exposes locked content.
- [ ] Mastery requires evidence from more than one session.
- [ ] Learning, behavior, experience, and equity/safety outcomes are shown and evaluated separately.
- [ ] Every active structural game element has a versioned mechanism card and implementation-fidelity evidence.
- [ ] Points cannot alter answers, grades, assessment difficulty, exemptions, or mastery thresholds.
- [ ] Public individual leaderboards remain disabled unless a separately governed opt-in experiment is approved.
- [ ] Simulator evidence distinguishes opening from prediction, meaningful interaction, reflection, and goal completion.
- [ ] Retention or mastery claims include delayed or changed-form performance evidence and report uncertainty.
