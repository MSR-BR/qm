# Requirements

- Start only after C13 is verified, C14 high-severity issues are resolved, and the user approves the final public experience.
- Define the campaign objective, target geography/language, audience, budget ceiling, conversion definitions, and landing pages with the user.
- Use only the final canonical domain in ad destinations.
- Verify GA4 measurement and, if approved, Google Ads conversion linkage/tags before launching spend.
- Address consent and privacy obligations applicable to the selected audience before enabling advertising or remarketing features.
- Draft keyword themes, negative keywords, ad copy, extensions, bidding approach, and exclusions; do not publish campaigns, spend money, or create audiences without explicit user approval.
- Avoid claims that misrepresent the book, author, academic institution, learning outcomes, price, access model, or endorsement.
