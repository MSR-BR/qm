# Requirements

- Begin only after C13–C14 are stable and the owner has accepted C15.
- Use only a user-supplied GA4 Measurement ID; never expose account credentials.
- Define and implement approved non-PII events for reading, search, simulator use, exercise generation, assessment completion, and sign-in intent.
- Do not send learner identity, report text, full generated answers, or sensitive URL query data to GA4.
- Verify implementation in GA4 DebugView.
