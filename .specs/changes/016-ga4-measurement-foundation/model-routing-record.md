## Fallbacks and escalations

1. Native computer-use initialization was blocked by the workspace symlink restriction.
2. The optional `agent-browser` executable was not installed.
3. The validation fallback used an isolated local Chrome profile controlled through Chrome DevTools Protocol; the Google Tag hostname was mapped to localhost and the Supabase service secret was blank, so the test emitted no external analytics writes.
4. After owner-scoped temporary access was enabled, the Supabase CLI still stalled at `Initialising login role...`. The safe fallback used the official Management API with the CLI PAT read only in memory from macOS Keychain: preflight reads confirmed the target project and prerequisite migration, the C16 migration was applied transactionally with an idempotency key, and postflight reads verified the resulting schema. No token was printed or written to the repository.
5. Google application-default authentication required an unacceptably broad persistent scope and was rejected. No workaround or credential broadening was attempted.
