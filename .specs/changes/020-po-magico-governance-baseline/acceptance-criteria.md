# Acceptance criteria

- The active Pó Mágico reference is versioned inside the QUANTUM repository.
- Future agents can find the product classification, content boundaries, architecture, service boundaries, and validation commands without relying on chat history.
- Every future non-trivial Change has a place to record actual model/routing and gate evidence.
- No learner-facing, database, service, credential, deployment, or content behavior changes occur in this Change.
- Repository checks and `git diff --check` pass.
