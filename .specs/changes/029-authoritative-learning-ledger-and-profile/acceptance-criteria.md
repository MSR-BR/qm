# Acceptance criteria

- [ ] Retry, refresh, and duplicate clicks cannot award twice.
- [ ] Profile projections reconcile exactly with eligible ledger events.
- [ ] Browser clients cannot authoritatively set points, mastery, badges, or message eligibility.
- [ ] Anonymous and cross-user access are denied; own-user/admin/service behavior is proven.
- [ ] Hidden answers, tokens, e-mails, and secrets are absent from logs and analytics.
- [ ] Historical migration has a reviewed dry run and count report before any write.
- [ ] Remote migration/deploy remains separately authorized.
