# Acceptance criteria

- [ ] No optional learning e-mail is sent without explicit opt-in.
- [ ] Frequency caps, quiet hours, pause, and unsubscribe are enforced server-side.
- [ ] Messages link only to reviewed, eligible content and explain the recommendation.
- [ ] Essential and optional communications use separate purposes and templates.
- [ ] Delivery failures do not block the learning app.
- [ ] Provider and analytics tests pass without exposing personal data.
- [ ] Communication reporting separates delivery, authentic learning action, learning evidence, and opt-out/adverse outcomes.
- [ ] Templates contain no threatened point loss, rank pressure, expiring mastery, or artificial urgency.
