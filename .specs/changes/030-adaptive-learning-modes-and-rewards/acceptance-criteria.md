# Acceptance criteria

- [x] Daily Challenge and chapter assessment are visibly and technically distinct.
- [x] Future practice responds to errors, help, confidence, successful retrieval, spacing, and prerequisites.
- [x] One correct answer cannot create mastery.
- [x] Simulator opening cannot create mastery or points.
- [x] Rewards are atomic/idempotent and errors never subtract points.
- [x] Recommendations explain why, source, duration, and alternative.
- [x] Deterministic fallback works without AI and locked content never enters the pool.
- [x] Public individual leaderboards remain absent.
- [x] Desktop/mobile/accessibility/failure gates pass locally.

These criteria describe the local candidate only. Managed Supabase application,
real-account history reconciliation, authenticated production proof and deployment
remain blocked behind the separately authorized C21/C27/release sequence.
