# Acceptance criteria

- [ ] Daily Challenge and chapter assessment are visibly and technically distinct.
- [ ] Future practice responds to errors, help, confidence, successful retrieval, spacing, and prerequisites.
- [ ] One correct answer cannot create mastery.
- [ ] Simulator opening cannot create mastery or points.
- [ ] Rewards are atomic/idempotent and errors never subtract points.
- [ ] Recommendations explain why, source, duration, and alternative.
- [ ] Deterministic fallback works without AI and locked content never enters the pool.
- [ ] Public individual leaderboards remain absent.
- [ ] Desktop/mobile/accessibility/failure gates pass.
