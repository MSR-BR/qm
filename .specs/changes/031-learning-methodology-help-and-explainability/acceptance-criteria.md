# Acceptance criteria

- [ ] Public English Help is readable without login and has a stable canonical URL.
- [ ] Policy version, update date, limits, privacy, AI boundary, error reporting, and references are visible.
- [ ] Contextual explanations match actual C30 behavior.
- [ ] No answer key, personal data, exploitable threshold, or security detail is disclosed.
- [ ] Navigation, sitemap, structured data, keyboard, zoom, mobile, and link tests pass.
